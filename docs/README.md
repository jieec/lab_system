## 五、答辩前 30 分钟快速过一遍

如果时间紧，按这个顺序看：

1. **答辩演示脚本** 第一节「演示前检查清单」→ 逐项确认环境可用
2. **答辩演示脚本** 第二节「演示动线」→ 记住 8 步顺序
3. **答辩问答准备** 的 Q1、Q2、Q3、Q8、Q17 → 最可能被问的五个问题
4. **项目总结与团队分工** 第三节「团队分工」→ 说清自己负责什么
5. **测试报告** 第七节「结论」→ 一句话总结质量情况

## 六、文档维护约定

| 约定 | 说明 |
|------|------|
| 改代码同步改文档 | 接口变更改 `接口文档.md`，表结构变更改 `数据库设计说明.md` |
| 文档不写密码 | 配置用占位符，真实密码通过环境变量传入 |
| 测试数字以实际执行为准 | `mvn test` 输出为准，不手写虚数 |
| 踩过的坑要记录 | 例如 `eq(column, null)` 的问题，写进设计说明，避免后人再犯 |
