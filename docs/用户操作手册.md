# 用户操作手册

> 本手册按角色说明系统怎么用，覆盖学生、教师、管理员、维修员四类用户。
> 演示账号密码统一为 `123456`。

---

## 一、通用操作

### 1.1 登录

1. 打开系统地址（本地开发：`http://localhost:5173`）。
2. 输入账号和密码，点击「登录」。
3. 登录成功后进入首页看板。

**常见问题**

| 现象 | 原因 | 处理 |
|------|------|------|
| 提示「账号或密码错误」 | 账号不存在或密码不对 | 核对账号；忘记密码找管理员重置 |
| 提示「账号已被停用」 | 管理员停用了该账号 | 联系管理员启用 |
| 登录后立刻被踢回登录页 | 密码被修改或账号被停用，旧 token 已失效 | 重新登录 |

> 系统采用令牌版本号机制：修改密码、被重置密码、账号被停用后，之前所有登录状态立即失效，需要重新登录。这是安全设计，不是故障。

### 1.2 个人中心

- 可修改：姓名、手机号、邮箱、头像。
- 不可自行修改：角色、学号/工号、信用分（由系统和管理员控制）。
- 修改密码需输入原密码，新密码长度 6–20 位。

### 1.3 站内信

右上角铃铛图标显示未读数。点击进入消息列表，可按已读/未读筛选，支持单条标记已读和全部已读。

消息类型包括：预约（审批结果、改期）、报修（派单、完成）、信用（扣分、恢复）、系统（公告推送）。

## 二、学生

### 2.1 预约实验室

1. 进入「实验室预约」。
2. 按楼栋或关键词找到实验室，点击进入。
3. 选择日期，页面展示该实验室当天的**时段时间轴**：
   - 灰色时段 = 已被占用，不可选。
   - 白色时段 = 空闲，可点击。
4. 选择开始和结束时间（单次时长 30 分钟至 8 小时）。
5. 填写使用人数、用途、备注。
6. 点击「提交预约」。

**提交后的两种结果**

| 实验室配置 | 结果 |
|------------|------|
| 需要审批 | 状态为「待审批」，等教师或管理员审批 |
| 免审批 | 状态直接为「已通过」，可立即使用 |

**提交失败的可能原因**

| 提示 | 说明 |
|------|------|
| 信用分不足，暂不能预约 | 信用分低于 60，或近 7 天爽约达 3 次 |
| 该时段已被预约 | 与他人时段冲突，换一个时段 |
| 该日期实验室闭馆 | 当天有闭馆安排 |
| 预约时长不符合要求 | 少于 30 分钟或多于 8 小时 |
| 不能预约过去的时间 | 开始时间早于当前时间 |
| 使用人数超出实验室容量 | 减少人数或换更大的实验室 |

### 2.2 查看和取消预约

- 「我的预约」列出全部预约，可按状态筛选：待审批 / 已通过 / 已驳回 / 已取消 / 已完成。
- 待审批和已通过的预约可以取消。**取消不扣信用分**。
- 已签到的预约不能取消，也不能改期。

### 2.3 签到

- 签到窗口：预约开始前 15 分钟开放。
- 在「我的预约」找到对应记录，点击「签到」。
- 签到成功后信用分 +2（满分 100 不叠加）。

**爽约规则（重点）**

> 预约结束后 15 分钟仍未签到，系统自动判定为**爽约**，扣 10 分信用分，并计入累计爽约次数。

所以约了不能来，务必提前取消，不要放着不管。

### 2.4 申请改期

在「我的预约」对已通过的预约点击「改期」，选择新的开始和结束时间，填写改期原因。

改期同样会做冲突检测，新时段被占用则改期失败。

### 2.5 查看信用分

进入「我的信用」可以看到：

- 当前信用分（0–100）。
- 累计爽约次数、近 7 天爽约次数。
- 是否被限制预约，以及限制解除时间。
- 信用变动明细：每次加分/扣分的时间、事件、变动值、变动前后分数、原因。

**信用规则速查**

| 规则 | 数值 |
|------|------|
| 初始分 | 100 |
| 爽约 | −10 |
| 签到 | +2 |
| 预约门槛 | ≥ 60 |
| 近期限制 | 近 7 天爽约 ≥ 3 次暂停预约 |
| 恢复申请 | 管理员通过后至少恢复至 70，7 天内最多通过一次 |

### 2.6 申请信用恢复

如果因特殊原因（生病、突发情况）导致爽约扣分，可在「我的信用」提交恢复申请，填写理由。管理员审核通过后信用分恢复。

审核结果会在站内信通知。

### 2.7 报修设备

1. 进入「设备报修」。
2. 选择设备（可下拉选，也可直接输入设备铭牌上的资产编号）。
3. 选择故障类型（硬件故障 / 软件故障 / 耗材缺失 / 其他）和紧急程度。
4. 填写故障描述（1–500 字），越具体越好，比如「屏幕无显示，电源指示灯亮」。
5. 提交后生成工单号。

**注意**

- 已报废的设备不能报修。
- 同一台设备已有未完成工单时，不能重复提交。
- 提交后可在「我的报修」查看进度和流转记录。

### 2.8 验收维修

维修员提交维修结果后，工单状态变为「待验收」，你会收到站内信。

在「我的报修」点「验收」，给 1–5 分评分并填写意见。验收后工单关闭。

如果维修不合格，可以在验收意见里说明，由管理员协调返修。

## 三、教师

教师拥有学生的全部权限，额外可以审批预约。

### 3.1 审批预约

1. 进入「预约审批」。
2. 默认展示「待审批」列表，可按实验室、日期、关键词（学生姓名/学号）筛选。
3. 查看申请详情：预约人、实验室、时段、人数、用途、当前信用分。
4. 点击「通过」或「驳回」：
   - 通过：可填审批备注（如「同意」）。
   - 驳回：**必须**填写驳回原因，会通过站内信告知学生。

**审批建议**

- 优先看信用分：低于 60 的学生系统已经拦截，不会出现在待审批里。
- 同一时段如有多条申请，通过一条后其余会因冲突失败，注意提示学生改期。
- 审批时系统会**二次校验时段冲突**，防止并发下重复占用。

### 3.2 查看预约总览

「预约管理」可查看全部预约（不只待审批），支持按状态、实验室、日期、关键词筛选，便于了解实验室使用情况。

## 四、管理员

管理员拥有全部权限。除上述功能外，还包括以下管理能力。

### 4.1 用户管理

| 操作 | 说明 |
|------|------|
| 新增用户 | 填写账号、姓名、角色、学号/工号、学院、联系方式。**初始密码固定为 123456** |
| 编辑用户 | 修改基本信息与角色 |
| 重置密码 | 重置为 123456，同时该用户所有登录状态立即失效 |
| 启用/停用 | 停用后无法登录，已登录的立即失效 |
| 删除用户 | 软删除，历史业务数据保留 |

> 角色决定权限：ADMIN 全部、TEACHER 审批、STUDENT 预约报修、REPAIRER 处理工单。改角色前确认业务影响。

### 4.2 实验室管理

- 新增/编辑实验室：编号、名称、楼栋、房间、容量、开放时间、负责人、简介。
- **是否需要审批**：设为「是」则学生提交后需审批；设为「否」则提交即通过。公共机房建议免审批，贵重仪器室建议需审批。
- 停用实验室后，该实验室不可被预约。

### 4.3 设备管理

- 新增/编辑设备：资产编号、名称、类别、所属实验室、型号、品牌、购置日期、价值、保管人。
- 变更状态：空闲 / 使用中 / 维修中 / 已报废。
- 资产编号必须唯一，对应设备铭牌，学生报修时可直接输入。

> 报修提交后设备会自动置为「维修中」，验收完成后恢复「空闲」，一般不需要手工改。

### 4.4 闭馆安排

1. 进入「闭馆安排」。
2. 新增闭馆：选择日期、填写原因。
   - **不选实验室 = 全校闭馆**（如法定节假日）。
   - **选择实验室 = 该实验室单独闭馆**（如设备检修）。
3. 闭馆日期在预约页面不可选，已存在的预约需要手工协调改期。

> 同一天同一范围不能重复添加闭馆，系统会提示「该日期已有闭馆安排」。

### 4.5 报修派单

1. 进入「报修管理」，默认展示「待派单」。
2. 查看故障描述、设备、紧急程度。
3. 点击「派单」，选择维修员。
4. 维修员会收到站内信。

**派单建议**：按故障类型分配（电器/网络/机械），紧急工单优先派给当前工单少的维修员。

### 4.6 信用管理

| 操作 | 说明 |
|------|------|
| 查看待审申请 | 「信用管理」→ 待审核列表 |
| 审核恢复申请 | 通过则信用分至少恢复至 70；驳回需填原因 |
| 手动调整信用分 | 输入目标分数和原因（5–200 字），用于纠正误判 |

**审核注意**

- 7 天内同一用户最多通过一次恢复申请，防止反复申诉无限复活。
- 恢复分数**不会**清除近 7 天爽约记录，近期限制仍按原时间解除。
- 每次调整都会写入信用流水，可追溯。

### 4.7 通知公告

- 发布公告：标题、正文、类型（通知 / 维护 / 系统）。
- 修改、删除、下架公告。
- 公告会出现在所有用户的公告列表和首页最新公告区。

### 4.8 审计日志

- 按模块、关键词筛选，查看操作人、动作、URI、IP、参数摘要、耗时、成功与否。
- 用于追查「谁在什么时候改了什么」。

**日志覆盖的操作**：登录、改密、用户增删改、实验室增删改、设备增删改与状态变更、预约提交/审批/取消/签到/改期、报修提交/派单/开始/完成/验收、信用调整与审核、闭馆增删、公告增删改、AI 助手确认操作。

### 4.9 首页看板

展示实验室总数、设备总数、今日预约数、待处理工单数、活跃用户数、低信用用户数，作为管理入口。

## 五、维修员

### 5.1 查看我的工单

进入「报修管理」，列表默认只显示分配给自己的工单（`scope=mine`），可按状态筛选。

### 5.2 处理工单

| 步骤 | 操作 | 状态变化 |
|------|------|----------|
| 1 | 点击「开始维修」 | 已派单 → 维修中 |
| 2 | 填写维修说明和费用，点击「提交结果」 | 维修中 → 待验收 |
| 3 | 等待报修人验收 | 待验收 → 已完成 |

**填写建议**

- 维修说明写清换了什么件、做了什么处理，便于后续追溯和同类故障参考。
- 费用填写实际支出，用于统计维修成本。

### 5.3 查看工单历史

工单详情页有流转记录时间轴：创建 → 派单 → 开始维修 → 完成 → 验收，每条记录含操作人、时间和内容。

## 六、AI 智能助手

### 6.1 打开方式

页面右下角悬浮按钮，点击展开对话窗口。

### 6.2 能做什么

| 类型 | 示例问法 |
|------|----------|
| 查询类（直接执行） | 「今天 A301 还有哪些空时段」「查一下我的预约」「三号实验室有哪些设备」 |
| 操作类（需确认） | 「帮我预约明天下午两点到四点」「报修一下示波器屏幕不亮」 |

### 6.3 确认卡片机制（重点）

涉及**写操作**（提交预约、提交报修等）时，助手不会直接执行，而是弹出确认卡片，显示：

- 将要执行什么操作
- 具体参数（实验室、时间、设备等）

**必须点击「确认」才会真正写入数据库**。点「取消」则不执行。

这个设计是为了防止 AI 理解偏差导致脏数据——比如把「明天下午两点」理解成今天，你可以在卡片上先看清参数再决定。

### 6.4 助手不可用时

如果后端未配置 LLM Key 或服务不可用，助手会降级为**规则模式**：能响应常见的关键词查询（如「我的预约」「实验室列表」），但无法进行复杂对话。

这不影响系统其他功能。

## 七、常见问题

| 问题 | 解答 |
|------|------|
| 为什么我预约不了？ | 依次检查：信用分是否 ≥60、近 7 天是否爽约 ≥3 次、时段是否冲突、当天是否闭馆、时长是否在 30 分钟–8 小时 |
| 签到按钮是灰的？ | 未到签到窗口（开始前 15 分钟），或预约尚未审批通过 |
| 已经被记爽约了怎么办？ | 提交信用恢复申请，管理员审核。7 天内只能通过一次 |
| 取消预约会扣分吗？ | 不会。只有「未签到且未取消」才算爽约 |
| 为什么我改不了密码？ | 新密码需 6–20 位，且需输入正确的原密码 |
| 为什么被踢下线了？ | 密码被修改、被管理员重置、或账号被停用，令牌已失效，重新登录即可 |
| 报修提交不了？ | 设备可能已报废，或已有未完成工单 |
| 公告看不到？ | 公告可能已下架，或状态为「未发布」 |
| 审计日志看不到？ | 仅管理员可见 |

## 八、操作红线

- 不要用他人账号登录，所有操作都有审计日志记录操作人和 IP。
- 不要恶意占位：预约后不来又不取消，会扣信用分并累计爽约次数。
- 管理员调整信用分必须填写真实原因，日志可追溯。
- 不要在故障描述里填写无关内容，会影响维修判断。
