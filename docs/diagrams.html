图 4 实验室预约与审批流程
flowchart TD
  A["学生选择实验室"] --> B["选择日期与起止时间"]
  B --> C{"时段冲突校验
实验室冲突 / 个人冲突"}
  C -- 冲突 --> C1["提示重新选择"] --> B
  C -- 通过 --> D{"实验室是否免审批"}
  D -- 是 --> E["直接生效 APPROVED"]
  D -- 否 --> F["生成预约单 PENDING"]
  F --> G["教师 / 管理员审批"]
  G --> H{"审批结果"}
  H -- 驳回 --> I["REJECTED 并记录意见"]
  H -- 通过 --> J["二次冲突校验"]
  J --> K["APPROVED 生效"]
  E --> L["按时到场使用"]
  K --> L
  L --> M["结束后自动置为 FINISHED"]
图 5 设备报修运维闭环流程
flowchart TD
  A["发现设备故障"] --> B["提交报修单 PENDING"]
  B --> C["设备状态置为维修中"]
  C --> D["管理员派单"]
  D --> E["ASSIGNED 指派维修员"]
  E --> F["维修员开始维修 REPAIRING"]
  F --> G["填写维修说明与费用"]
  G --> H["DONE 待验收"]
  H --> I{"报修人验收"}
  I -- 不通过 --> F
  I -- 通过 --> J["VERIFIED 已完成"]
  J --> K["设备恢复空闲"]
图 6 预约单状态流转
stateDiagram-v2
  [*] --> PENDING : 提交申请
  [*] --> APPROVED : 免审批实验室
  PENDING --> APPROVED : 审批通过
  PENDING --> REJECTED : 审批驳回
  PENDING --> CANCELLED : 申请人取消
  APPROVED --> CANCELLED : 开始前取消
  APPROVED --> FINISHED : 时段结束
  REJECTED --> [*]
  CANCELLED --> [*]
  FINISHED --> [*]
