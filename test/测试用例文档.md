## 测试执行方式

```bash
cd lab-backend
mvn test
```

或仅运行综合测试：

```bash
mvn test -Dtest=SystemCoreTest
```

## 测试覆盖率说明

| 模块 | 覆盖的核心规则 | 测试策略 |
|------|---------------|----------|
| 信用分策略 | 门槛检查、扣分下限、加分上限、连续爽约 | 边界值 + 等价类 |
| 预约状态机 | 合法流转、非法流转、终态、null处理 | 状态迁移 + 决策表 |
| 时间窗口 | 相同/重叠/包含/相邻/分离/跨天 | 边界值 + 参数化 |
| 响应结构 | 成功/失败/分页/空结果 | 等价类 |
| JWT认证 | 签发/解析/版本/密钥/过期/篡改 | 边界值 + 异常 |
