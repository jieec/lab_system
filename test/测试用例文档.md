## 十二、执行方式

```bash
cd lab-backend

# 全量
mvn test

# 单类
mvn test -Dtest=SystemCoreTest
mvn test -Dtest=DtoValidationTest
mvn test -Dtest=ReservationServiceTest

# 生成 HTML 报告
mvn test surefire-report:report
```

预期结果：

```
[INFO] Tests run: 199, Failures: 0, Errors: 0, Skipped: 0
[INFO] BUILD SUCCESS
```
